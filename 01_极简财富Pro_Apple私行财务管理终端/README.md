---

## 🌟 核心设计与功能亮点

1. **顶级 Apple 工业级视觉体验**
   - 采用 SF Pro 字体系、精确流体阴影与微边框克制留白。
   - 浅色极简底面与纯黑高对比度数值排版，消除一切冗余装饰。

2. **双环资产盈亏（P&L）动态圆盘**
   - 原生 Canvas 渲染的高性能动态甜甜圈图表，实时计算资产配置占比。
   - 资产总额、各账户盈亏浮动、现金流与持仓权重一览无余。

3. **自然语言智能流水记账（NLP Ledger）**
   - 支持自然语言解析输入（如“打车花了 35 块人民币”自动归类为交通支出并扣减账户余额）。
   - 完整的多账户联动扣款、月度预算监控与零钱余额监控。

4. **多币种实时折算引擎**
   - 内置多币种汇率换算与资产统一法币计价能力（USD / CNY / AUD / HKD 等）。

5. **iMessage 拟真风格 AI 财务顾问**
   - 拟真对话交互，支持本地诊断与资产配置平衡算法。

6. **零依赖单文件独立运行架构**
   - 极简单文件设计（Single-File Architecture），无需配置 Node 环境或复杂数据库，双击浏览器或通过 GitHub Pages 即可秒级开启，数据安全持久化保存在用户本地（LocalStorage），隐私完全自主。

---

## 🚀 快速上手

1. 浏览器直接双击打开 `index.html` 即可完整体验。
2. 支持一键部署到 **GitHub Pages** 或 **Vercel** / **Cloudflare Pages**。
