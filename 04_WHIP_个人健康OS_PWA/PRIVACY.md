# 隐私说明

VITAL 不要求账户，没有广告 SDK、行为分析或自动健康云备份。可选 Supabase 身份接入目前未配置，登录提交禁用。健康记录、备注、照片与 GPS 保存在当前浏览器 IndexedDB。没有主动发送健康数据的 fetch/上传路径。首次加载和应用更新会向托管方获取静态资源；托管平台可能保留一般 HTTP 访问日志，独立于应用健康数据库。

定位只在明确启动户外运动后调用浏览器权限请求；暂停/结束/卸载监听时停止。切后台即暂停，不持续收集日常位置。路线示意图不请求外部地图瓦片或发送坐标。

照片通过系统文件选择器读取并在本地压缩。进展照片不上传。备份文件包含敏感健康记录、照片、坐标与个人目标，未做自定义加密；请存入你信任且受设备保护的位置。浏览器的同源隔离和系统设备保护不等于应用级端到端加密。Face ID 应用锁未实现。

用户可导出 JSON / CSV，可逐条删除，或输入「删除全部数据」永久清空本地记录和自建目录。已导出的文件不受应用删除影响，需要用户自行管理。参考目录和默认设置会重新初始化，不包含私人记录。

无痕模式、手动清理、容量不足、系统回收、更换域名、浏览器或主屏幕入口都可能影响储存。持久储存申请不保证成功。默认没有通知权限请求。

静态部署建议启用 HTTPS、CSP、no-referrer 与权限策略；Cloudflare `_headers` 已随 dist 发布，其他平台须自行配置相同策略。任何后续云/AI集成必须单独取得明确同意，不能默认传输健康数据库。

## 可选联网功能（本轮新增）

- 天气：先选择城市或明确点选当前位置，向 Open-Meteo 发送城市名称查询或城市坐标；当前位置仅发送四舍五入至0.01°的坐标，不上传健康数据。可在设置中关闭并清除天气缓存。
- 食物辅助识别：经用户点击同意下载，向 Hugging Face 请求公开 CLIP 模型文件；WASM运行库随本网站部署。照片在本机缩小和推理，不发送给模型服务器。第三方可能保留模型下载请求的一般HTTP日志。模型缓存由浏览器管理，停止识别会结束worker。
- 身份：当前没有Supabase项目或配置。日后用户接入后，邮箱、密码和身份会话由Supabase处理，仅用于登录；密码不写入本机健康数据库。连接前须核验所选项目与Redirect URL。
- 头像、自律事件与含糖饮料记录属于本机数据，随完整JSON备份导出；敏感事件不会用于遥测或发布。公开网站仅含静态代码和参考目录。
