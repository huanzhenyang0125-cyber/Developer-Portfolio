# 个人作品集

金融科技、数据分析与数字产品实践。主页汇集信用风险研究、资产管理、健康记录、工业产品展示、文献服务和专业方向探索项目。

[查看作品集](https://huanzhenyang0125-cyber.github.io/Developer-Portfolio/)

## 精选项目

| 作品 | 内容 | 入口 |
| --- | --- | --- |
| Credit Risk Decision Lab | 台湾信用卡历史数据的违约预测、模型验证和审查容量分析 | [交互工作台](https://huanzhenyang0125-cyber.github.io/default-credit-card-prediction/) · [代码与报告](https://github.com/huanzhenyang0125-cyber/default-credit-card-prediction) |
| 极简财富 Pro | 多账户资产配置和盈亏的交互原型 | [项目案例](case-studies/wealth-pro.html) · [在线原型](https://wealth-pro-ehw.pages.dev) |
| WHIP 个人健康 OS | 本地优先的健康记录应用 | [项目案例](case-studies/whip.html) · [在线应用](https://whip-health.pages.dev) |
| 奥尼斯工具 | 工业产品展示与询价门户 | [在线项目](https://honest-tools.pages.dev) |
| 学术文献代查系统 | DOI 或关键词提交、计价与后台工单处理的双端原型 | [在线项目](https://academic-express.pages.dev) |
| 专业与职业方向探索 | 江苏考生的专业、职业方向与志愿信息查询原型 | [在线项目](jiangsu-gaokao/) |

项目中的财务数值及客户情景用于演示；信用风险结果基于历史数据，不用于实际信贷决策。专业探索原型的信息与结论需核对来源及更新时效。

## 本地查看

在仓库根目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/`。
